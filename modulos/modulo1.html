Módulo 1: Como usar esta apostila

Este módulo é um exemplo. Troque os textos pelo seu conteúdo.

Estrutura de um módulo

Cada módulo é um arquivo HTML dentro da pasta modulos/. Ele segue três blocos: explicação, exemplo e atividade.

Dica: use a classe caixa dica para destacar avisos e observações importantes.

Como criar um módulo novo

Copie o modulo2.html, renomeie e edite o texto. Depois adicione uma linha na lista MODULOS do arquivo js/app.js.

Como publicar as mudanças

Salve os arquivos e rode git add ., git commit -m "mensagem" e git push. O site atualiza em cerca de 1 minuto.
